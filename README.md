# 🐍 DSA Python: Array Data Structure

A comprehensive collection of core Array concepts, operations, and popular interview problem solutions implemented in **Python 3**.

---

## 📌 Features & Topics Covered

- **Basic Operations:**
  - Min & Max Element Search
  - Array Reversal (Two Pointer Approach)
  - Second Largest Element Detection
- **Key Algorithms:**
  - **Two Sum Problem** (Optimized using Hash Maps)
  - **Kadane's Algorithm** (Maximum Subarray Sum)
  - **In-Place Array Manipulation** (Move Zeroes)
